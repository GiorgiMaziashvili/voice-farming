# Farm Builder

When implementing a farm-game feature:

1. Read AGENTS.md first.
2. Use the official PixiJS skills when PixiJS-specific behavior is involved.
3. Implement only the requested feature.
4. Keep game logic separate from rendering when practical.
5. Use TypeScript with clear types.
6. Avoid unnecessary abstractions.
7. Clean up timers, ticker callbacks, and event listeners when they are no longer needed.
8. Run the build after making changes.
9. Fix TypeScript or build errors before finishing.
10. Briefly summarize what changed.
