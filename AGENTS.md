Use the official PixiJS skills.

We are building a small PixiJS v8 farm game using TypeScript.

For this first task only:

1. Create a farm game scene.
2. Use a simple rectangular background for the farm.
3. Create a Player class.
4. Render the player as a square using PixiJS Graphics.
5. Let the player move using WASD and arrow keys.
6. Movement must use the PixiJS ticker and delta time.
7. Keep the player inside the game boundaries.
8. Keep game logic separated from rendering where reasonable.
9. Do not add animals, audio, assets, menus, or unnecessary features yet.
10. Run the app and fix TypeScript/build errors.

Keep the implementation simple and easy to understand.
